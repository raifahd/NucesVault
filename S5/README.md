### Architecture & Features

- **Modular Design:** Standalone HTML modules with single-view topic pagination.
- **Hub Search:** Client-side real-time multi-subject filter on [`index.html`](./index.html).
- **Responsive Layout:** Off-canvas drawer navigation for mobile, static sidebar for desktop.
- **Academic & Exam Prep:** Integrated concept definitions, pro tips, common pitfalls, and quiz banks.

### Quick Start

Open [`index.html`](./index.html) in any modern browser, or launch via local HTTP server:

```bash
# Optional local server
python3 -m http.server 8000
# or
npx serve .
```
