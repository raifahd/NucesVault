Intro to AI

1Introduction to AI Agents

The core loop: Perceive → Decide → Act

At its core, Artificial Intelligence is about an agent perceiving an environment, deciding what to do, and acting to achieve some objective. It is not just about "thinking", but rather a continuous cycle of: Perceive → Decide → Act.

The Agent-Environment Interaction

Definition
Agent: An entity that perceives its environment and takes actions. (e.g., a self-driving car, a chess program, or a human).
Definition
Environment: Everything outside the agent that it interacts with. If the agent makes decisions, the environment is the world it operates in.

To interact with the environment, agents rely on two main components:

  • Sensors: The input mechanism that allows an agent to perceive its environment (e.g., cameras, microphones, GPS).
  • Actuators: The output mechanism used by the agent to physically or digitally affect its environment (e.g., motors, steering wheels, API calls).
Definition
Percept: The specific information an agent receives from its sensors at a particular moment.
Definition
Action: The decision or output of the agent, executed via an actuator.
Example

A Self-Driving Car

  • Sensors: Cameras see the road, cars, pedestrians.
  • Percept: "Red traffic light 50m ahead."
  • AI Agent: Processes the percept and makes a decision.
  • Action: AI decides to brake.
  • Actuator: The car's braking system engages.
  • Environment: The car slows down on the road.

Measuring Success: Performance Measure

How do we know if an AI is successful? We need a way to evaluate its behavior.

Definition
Performance Measure: A metric that tells us how well an agent is doing its job. It defines the objective the AI is trying to optimize.
Pro Tip
Pro Tip: When defining a performance measure, focus on what you want the agent to achieve in the environment, not how you want the agent to behave. E.g., for a vacuum, measure "amount of dirt removed", not "time spent vacuuming".

The Rational Agent

This is one of the most foundational concepts in AI. We design agents to be rational.

Definition
Rational Agent: An agent that chooses the action expected to maximize its performance measure, given its percept history, built-in knowledge, and available actions. In short: doing the best it can with the information it has.
Common Mistake
Rationality vs. Perfection
Students often confuse rationality with omniscience (knowing everything). A perfect agent knows the exact outcome of its actions and the future. A rational agent only maximizes expected performance based on what it currently knows. If a self-driving car brakes for a mannequin thinking it's a person, it's still acting rationally based on its imperfect sensors!

Topic 1 Summary

  • AI is a cycle of Perceive → Decide → Act.
  • Sensors take in percepts; actuators carry out actions.
  • The Performance Measure defines success.
  • A rational agent maximizes expected success given its available information, but it is not perfect or omniscient.
Practice Q1: Identify the components for a Spam Filter AI.

Answer:

  • Agent: Spam Filter Program
  • Environment: Email inbox, incoming messages
  • Sensors: Email text parser, sender info reader
  • Actuators: Mechanism to flag as spam or move to folder
  • Performance Measure: High accuracy in catching spam, minimal false positives (not blocking legitimate emails)
Practice Q2: Why is a thermostat considered a basic agent?

Answer: It fits the definition: it perceives the environment (room temperature) through a sensor (thermometer), decides what to do based on a set point, and acts through an actuator (turning the heater on/off).

Practice Q3: Is a poker bot that bluffs and loses the game irrational?

Answer: Not necessarily. A rational agent maximizes its expected outcome. In poker, you have incomplete information (hidden cards). Bluffing might mathematically be the rational choice with the highest expected value given the bot's hand and opponent tendencies, even if it happens to lose that specific hand. Rationality does not guarantee a perfect outcome.

2The PEAS Framework

Defining the task environment for any AI system

When designing an AI system, the first step is to formally define the problem it needs to solve. We call this the Task Environment.

Definition
Task Environment: The complete specification of the problem the agent operates in, described using the PEAS framework.

PEAS stands for:

  • P - Performance Measure: How do we measure success?
  • E - Environment: Where does the agent operate and what does it interact with?
  • A - Actuators: How does the agent act upon the world?
  • S - Sensors: How does the agent perceive the world?

Examples of PEAS

Agent Type Performance Measure Environment Actuators Sensors
Self-Driving Car Safety, speed, legality, comfort Roads, traffic, pedestrians, weather Steering, brakes, accelerator Cameras, radar, lidar, GPS
Vacuum Robot Cleanliness, efficiency, battery life House, furniture, dirt, walls Wheels, vacuum motor, brushes Dirt sensor, collision sensor, camera
Chess AI Win game / maximize win probability Chess board, opponent Output move (e.g., GUI update) Board state input, opponent moves
Medical Diagnosis AI Correct diagnosis, patient safety Patient, medical history, lab results Output report, suggest tests/treatment Symptom input, blood tests, X-rays
Exam Hint
Exam Hint: You will almost certainly be asked to write a PEAS description for a novel scenario in an exam. Remember that software bots (like the Chess or Medical AI) have digital sensors (like keyboard inputs or database reads) and digital actuators (like screen displays or API requests). Agents do not need physical bodies!

Topic 2 Summary

  • A Task Environment specifies the problem for an AI.
  • PEAS is the standard framework for describing a task environment.
  • Defining PEAS is the necessary first step before designing the agent's internal architecture.
Practice Q1: Create a PEAS description for an Automated English Tutor.

Answer:

  • Performance Measure: Student's test score improvement, engagement time.
  • Environment: The software platform, the student user.
  • Actuators: Displaying text/questions on screen, playing audio hints, providing grades.
  • Sensors: Keyboard/mouse input (student answers), microphone (if assessing speaking).
Practice Q2: Identify the 'Actuator' in a movie recommendation system (like Netflix).

Answer: The actuator is the UI element or algorithm output that displays the recommended movie list on the user's screen.

Practice Q3: Why is it important to clearly define the Performance Measure in PEAS?

Answer: Because a rational agent will optimize whatever performance measure you give it. If you give a vacuum agent a measure of "amount of dirt cleaned", it might dump its own dirt back onto the floor just to clean it up again and inflate its score! A well-defined measure (e.g., "cleanliness of floor minus energy used") aligns the AI's goals with human desires.

3Agent Architecture & Types

Building the decision-making brain of an agent

Once we know the task environment (PEAS), we need to build the agent itself.

Definition
Agent Architecture: The computing device, hardware, or platform that the agent runs on (e.g., robot body, a laptop, a cloud server).
Definition
Agent Program: The actual software or algorithm that implements the decision-making process.

Therefore: Agent = Architecture + Program

The Agent Function

Mathematically, an agent's behavior is described by the Agent Function, which maps any given percept sequence (everything it has seen so far) to an action. 

f: P* → A

# Given a history of percepts (P*), pick an action (A).

Four Types of Agent Programs

There are four classic ways to design the decision-making logic of an agent, ranging from simple to highly complex.

1. Simple Reflex Agent

Acts purely based on the current percept, ignoring history. It uses simple Condition-Action (if-then) rules.

  • Pros: Fast, simple, takes little memory.
  • Cons: Fails in complex environments because it has no memory.
  • Example: if car_in_front_brakes: apply_brakes()

2. Model-Based Reflex Agent

Maintains an internal state (a "model" of the world) based on percept history. This allows it to handle partially observable environments.

  • How it works: Current Percept + Previous Knowledge = Updated Internal State → Action.
  • Example: A car tracking another car in its blind spot. It can't see the car right now, but its internal model remembers the car moved there 2 seconds ago.

3. Goal-Based Agent

Uses a world model, plus goal information, to select actions that achieve that goal. It plans ahead.

  • How it works: "What will happen if I do X? Will that help me reach my goal?"
  • Example: A navigation AI searching for a route from Lahore to Islamabad. It considers future steps to reach the destination.

4. Utility-Based Agent

Similar to goal-based, but instead of just asking "Does this reach the goal?", it asks "How happy does this make me?" It maximizes a utility function.

  • How it works: Evaluates multiple paths to the goal and chooses the best one based on tradeoffs (e.g., speed vs. safety vs. cost).
  • Example: A GPS app offering the fastest route vs. the route with no tolls. It optimizes for the most "utility".

Topic 3 Summary

  • The Agent Function maps percept histories to actions.
  • Simple Reflex Agents act on the current percept only.
  • Model-Based Agents remember past states.
  • Goal-Based Agents plan to achieve a specific target.
  • Utility-Based Agents optimize to find the best way to achieve a target.
Practice Q1: A chess bot evaluates millions of future board states and scores them to find the optimal move. What type of agent is this?

Answer: Utility-Based Agent. It is not just trying to reach a goal state (checkmate), but it is evaluating the "utility" (score) of intermediate states to pick the objectively best path forward.

Practice Q2: A smart thermostat turns on the AC when it reads a temperature > 25°C. What type of agent is this?

Answer: Simple Reflex Agent. It only looks at the current percept (temperature) and uses a simple condition-action rule.

Practice Q3: Why is a Simple Reflex Agent a bad choice for a maze-solving robot?

Answer: A maze often requires remembering where you have already been (internal state) to avoid walking in circles. A simple reflex agent only knows what its sensors see right now (e.g., "wall in front"), so it might get stuck in an infinite loop turning back and forth.

4The Four AI Approaches

How researchers have historically defined "intelligence"

Historically, researchers have defined the goal of Artificial Intelligence in four distinct ways. These are divided by whether we care about thinking vs. acting, and humanly vs. rationally.

Thinking Acting
Humanly Does it think like a human? (Cognitive Modeling) Does it behave like a human? (The Turing Test)
Rationally Does it reason perfectly/logically? (Laws of Thought) Does it make the best decisions? (Rational Agents)

1. Acting Humanly (The Turing Test)

Goal: Make machines behave so human-like that they are indistinguishable from real humans. Alan Turing proposed the Turing Test: if a human interrogator cannot tell whether they are chatting with a machine or a human, the machine passes.

2. Thinking Humanly (Cognitive Modeling)

Goal: Figure out exactly how the human brain works, and build software that mimics that process (e.g., using neural networks inspired by biology). Closely tied to psychology and neuroscience.

3. Thinking Rationally (Laws of Thought)

Goal: Build systems that reason flawlessly using formal logic (syllogisms). E.g., "A=B, B=C, therefore A=C".
Problem: The real world is full of uncertainty, and not everything can be neatly defined in absolute logical terms.

4. Acting Rationally (Rational Agent Approach)

Goal: Build agents that choose actions to maximize their performance measure. This is the modern standard for AI.

Key Insight
Why modern AI focuses on Acting Rationally: We usually don't care if an AI "thinks" the way humans do, or if it can perfectly logically prove every step. We care about results. A self-driving car doesn't need to drive exactly like a human (humans crash!); it just needs to drive safely and efficiently (rationally).
Common Mistake
Rationality vs Human Behavior
Humans are not perfectly rational. We make emotional decisions, mistakes, and have biases. Therefore, "Acting Humanly" and "Acting Rationally" are very different goals!

Topic 4 Summary

  • AI approaches are split along human-like vs. rational, and thinking vs. acting.
  • Acting Humanly focuses on mimicking human behavior (Turing Test).
  • Acting Rationally focuses on maximizing objective success.
  • Modern AI courses almost exclusively focus on building Rational Agents.
Practice Q1: If a conversational AI intentionally makes typos to seem more realistic, which AI approach is its designer following?

Answer: Acting Humanly. The goal is to mimic human behavior (imperfections and all) to pass as human, not to perfectly transmit information.

Practice Q2: Why did traditional "Thinking Rationally" (Symbolic AI) struggle with real-world problems like vision or speech?

Answer: Because formal logic requires absolute certainty (True/False). Real-world sensor data (like a blurry camera image) is noisy and uncertain. Rational thought requires dealing with probabilities, which strict symbolic logic struggled with.

Practice Q3: Under the "Acting Rationally" framework, is an AI required to explain its internal thought process to a user?

Answer: No. The rational agent approach only evaluates the action taken and its effect on the performance measure. While explainability is useful for humans, it is not a requirement for an agent to be considered rational, so long as it chooses the optimal action.
