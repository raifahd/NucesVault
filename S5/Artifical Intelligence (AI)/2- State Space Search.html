State Space Search

1States and State Spaces

How AI views the world as a series of connected states

Many problems in AI involve answering questions like: Is there a guaranteed solution? Will the search loop infinitely? Is the solution optimal? To systematically answer these, AI frames problems using a State Space Search.

Definition
State: A snapshot of the world or the problem at a specific moment in time.
Definition
State Space: The complete set of all possible states that can be reached from the initial state through any sequence of valid actions.

Why use State Spaces?

By mapping out a problem as a state space, we transform decision-making into a mathematical search problem. The AI doesn't need to "understand" the nuances of a game; it just needs to find a path from the Initial State to the Goal State.

Example

The Tic-Tac-Toe State Space

Imagine a blank 3x3 board. This is our Initial State. When you place an 'X', the board transitions into a new state. Every legal move generates a branch to a new state. The collection of every possible board configuration (win, lose, draw, or mid-game) forms the Tic-Tac-Toe state space!

Common Mistake
State Space vs Game Tree Size
Students often think the number of states equals the number of nodes in the game tree. This is false! A game tree can have identical nodes (e.g., reaching the same board configuration through a different sequence of moves). The State Space only counts unique states.

Key Takeaways

  • A State represents a distinct configuration of the problem.
  • A State Space contains all possible distinct states.
  • Problem-solving in AI is largely about navigating through this state space efficiently.
Practice Questions
Easy: What is the initial state in a game of Chess?

Answer: The standard setup of the 32 pieces on the 8x8 board before any moves are made.

2Formal Definition & Graph Theory

Translating state spaces into math

To program a computer to solve a problem, we must formally define the state space using graph theory concepts.

Formal Definition of State Space [N,A,S,GD]

A State Space is represented as a four-tuple:

  • N: The set of nodes or states of the graph.
  • A: The set of arcs (links/edges) between nodes, representing legal moves or actions.
  • S: A nonempty subset of N containing the start state(s).
  • GD: A nonempty subset of N containing the goal state(s).
Definition
Solution Path: A sequence of arcs (a path) through the graph that starts at a node in S and ends at a node in GD.

Graph Theory Concepts

State spaces are almost always visualized and manipulated as graphs or trees. Here are the core definitions you need to know:

Term Definition
Graph A collection of nodes connected by arcs.
Directed Graph A graph where arcs have a specific direction (you can go A → B, but not necessarily B → A).
Parent & Child If an arc goes from N1 to N2, N1 is the parent and N2 is the child.
Rooted Graph A graph with a unique node (the root) from which all paths originate. (e.g., the empty board in a game).
Leaf (Tip) Node A node with no children (e.g., a finished game board).
Cycle (Loop) A path that visits the same node more than once.
Tree A specific type of graph where there is exactly one unique path between any two nodes. By definition, trees contain no cycles.
Pro Tip
Expert Systems and Graphs: In rule-based expert systems, nodes represent our knowledge of a problem at a stage, and arcs represent the application of an IF...THEN... rule to generate new knowledge.

Key Takeaways

  • State Space = [Nodes, Arcs, Start States, Goal States].
  • A graph is made of nodes (states) and arcs (actions).
  • Trees are cycle-free graphs with unique paths.

Applying state spaces to classic problems

Let's look at how we represent classic AI problems using the State Space concepts we just learned.

1. Tic-Tac-Toe

2. The Traveling Salesperson Problem (TSP)

Problem: Given a map of cities and the distances between them, find the path with the minimum distance that visits every city exactly once and returns to the starting city.

State Space Representation:

  • Nodes (N): Represent a set of visited cities and the current location.
  • Arcs (A): Labeled with a weight indicating the distance/cost of traveling between connected cities.
  • Start State (S): A home city with no other cities visited.
  • Goal State (GD): A state where the path contains a complete circuit (all cities visited and returned to home) with minimum cost.
Insoluble Variations
If cities are not always reachable directly from each other (e.g., to get from A to B you must go through C, but you've already visited C), there might be NO solution for that specific map!
The Complexity Nightmare
Exhaustive search is often impossible! There are 9! paths in tic-tac-toe. 1040 paths in Checkers, and 10120 paths in Chess! TSP has a complexity of (n-1)! cost-weighted paths. This is why we need smart Search Algorithms.

Key Takeaways

  • Tic-Tac-Toe state spaces are smaller than their game trees due to identical states.
  • TSP requires finding an optimal cost path in a massive factorial-complexity state space.
  • Exhaustive search is infeasible for non-trivial problems.
Practice Questions
Medium: What is the maximum depth of a Tic-Tac-Toe game tree?

Answer: 9 levels deep. There are 9 empty squares on the initial board, and one square is filled per turn. Therefore, the board is full (leaf node) at level 9 at the latest.
