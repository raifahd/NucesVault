1Module 1: Introduction to AI

Easy What does the acronym PEAS stand for?

Answer: Performance measure, Environment, Actuators, Sensors. It is the framework used to completely specify the task environment for an AI agent.

Medium Explain the difference between a Model-Based Reflex Agent and a Goal-Based Agent.

Answer: A Model-Based Reflex Agent acts based on its current percept and its internal memory/model of past states (e.g. "I remember the car went into my blind spot"). A Goal-Based Agent also has an internal model, but it additionally uses goal information to project into the future ("If I take action X, will it get me closer to destination Y?"). The key difference is that goal-based agents plan ahead, while model-based reflex agents just react to the current (and remembered) state.

Hard Why is a rational agent not necessarily perfect/omniscient? Give a real-world example.

Answer: Rationality is about maximizing expected performance based only on the percepts it has received and its built-in knowledge. Perfection requires knowing the actual outcome of all actions in advance (omniscience), which is usually impossible.

Example: A rational poker-playing AI might go all-in with Four of a Kind, expecting to win 99.9% of the time based on the cards it sees. If the opponent happens to hold a Straight Flush and wins, the AI's decision was still completely rational given its information, even though the outcome was not perfect.

Medium Define the PEAS for a robotic vacuum cleaner.

Answer:
- Performance: Amount of dirt collected, time taken, battery efficiency, not bumping into pets.
- Environment: The room, furniture, walls, floor type.
- Actuators: Wheels, vacuum suction motor, sweeping brushes.
- Sensors: Bump bumper, dirt sensor, cliff sensor (to avoid falling down stairs), internal battery meter.

2Module 2: State Space Search

Easy What are the four components of a formal state space definition [N,A,S,GD]?

Answer:
N = Nodes (states)
A = Arcs (legal moves/actions between states)
S = Start state(s)
GD = Goal state(s)

Easy What makes a tree different from a general graph?

Answer: A tree is a specific type of graph that contains absolutely no cycles. There is exactly one unique path between any pair of nodes.

Medium In Tic-Tac-Toe, why is the State Space smaller than the total number of nodes in the game tree?

Answer: The game tree branches out for every single move sequence, treating "X top-left then O center" as a different path from "O center then X top-left". However, both paths result in the exact same physical board configuration. The state space only counts unique physical configurations (states), so it is much smaller because it doesn't duplicate identical states reached through different move orders.

Hard You are solving the Traveling Salesperson Problem (TSP) on a map with 5 cities. Assuming all cities are fully connected to each other, how many possible paths (including the return home) must be checked for an exhaustive search?

Answer: For n cities, the complexity is (n-1)!.
Since n = 5, the number of paths is 4! = 4 * 3 * 2 * 1 = 24 paths.
(Note: The starting city is fixed, so we have 4 choices for the first stop, 3 for the second, 2 for the third, and 1 for the final stop before returning home).

3Module 3: Uninformed Search Algorithms

Easy What data structures do BFS and DFS use to track the frontier (NSL)?

Answer:
BFS (Breadth-First Search): Uses a Queue (FIFO - First In, First Out).
DFS (Depth-First Search): Uses a Stack (LIFO - Last In, First Out).

Medium Compare BFS and DFS regarding Completeness and Space Complexity.

Answer:
- Completeness: BFS is complete (always finds a goal if it exists). DFS is NOT complete (can get stuck in an infinite branch).
- Space Complexity: BFS is highly inefficient (exponential space, O(b^d)) because it stores entire levels in memory. DFS is highly efficient (linear space, O(b*d)) because it only stores the current single path.

Medium How does Iterative Deepening Search (IDS) get the "best of both worlds"?

Answer: IDS repeatedly runs DFS, incrementing the depth limit by 1 each time. Because it uses DFS under the hood, it keeps the memory requirement low (linear space). Because it checks depth 0, then depth 1, then depth 2 completely, it acts like BFS, ensuring it finds the shortest path (optimal) and never gets stuck in an infinite branch (complete).

Hard Why is the goal test applied to a node when it is selected for expansion in Uniform-Cost Search, rather than when it is first generated?

Answer: Because Uniform-Cost Search evaluates paths based on varied costs, not just depth. If the algorithm generates a goal node via a path costing 100, it shouldn't immediately declare victory. There might be an unexpanded node in the queue that leads to the goal with a total cost of only 50. By waiting to test the goal until it is the absolute cheapest node popped off the queue for expansion, UCS guarantees it has found the mathematically cheapest path.

Hard Describe the four tracking lists used in Backtracking search.

Answer:
1. SL (State List): The active path currently being evaluated.
2. NSL (New State List): The frontier of nodes waiting to be evaluated (siblings of nodes on the SL).
3. DE (Dead Ends): A "graveyard" of states that are known to lead to failure, preventing the algorithm from retrying them.
4. CS (Current State): The exact state being looked at right now.
