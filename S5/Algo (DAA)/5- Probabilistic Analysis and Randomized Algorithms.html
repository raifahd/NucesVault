Module 5 — Probabilistic Analysis & Randomized Algorithms

1The Hiring Problem

Analyzing expected costs

Suppose you need to hire an office assistant. The employment agency sends one candidate each day. If the candidate is better than your current assistant, you fire the current one and hire the new one. Interviewing is cheap (cᵢ), but hiring and firing is expensive (cₕ).

HIRE-ASSISTANT(n)
1  best = 0   // candidate 0 is a least-qualified dummy candidate
2  for i = 1 to n
3      interview candidate i
4      if candidate i is better than candidate best
5          best = i
6          hire candidate i

Worst-case Analysis

In the worst case, the candidates arrive in strictly increasing order of quality. You hire every single person you interview. The total hiring cost is O(cₕ · n).

Probabilistic Analysis

We often use probability to analyze the average-case running time (or expected cost). This assumes something about the distribution of the inputs. For the hiring problem, we assume the applicants come in a random order (a uniform random permutation).

2Indicator Random Variables

A powerful tool for probabilistic analysis

Definition
Indicator Random Variable: Given a sample space S and an event A, the indicator random variable I{A} is 1 if A occurs, and 0 if A does not occur.

Lemma 5.1: The expected value of an indicator random variable associated with an event A is equal to the probability that A occurs. E[X_A] = Pr{A}.

Detailed Proof

Solving the Hiring Problem Cost

Let Xᵢ be the indicator random variable that candidate i is hired. Xᵢ = 1 if hired, 0 otherwise.

Candidate i is hired if and only if they are the best candidate among the first i candidates. Since candidates arrive in random order, any of the first i candidates is equally likely to be the best so far.

E[Xᵢ] = Pr{candidate i is hired} = 1 / i.

The total expected number of hires X is the sum of Xᵢ. By linearity of expectation:
E[X] = E[Σ_{i=1}^{n} Xᵢ] = Σ_{i=1}^{n} E[Xᵢ] = Σ_{i=1}^{n} (1/i).

This summation is the harmonic series, which can be bounded as:
Σ_{i=1}^{n} (1/i) = ln n + O(1).

Therefore, the expected hiring cost is O(cₕ ln n), which is a massive improvement over the worst-case O(n).

3Randomized Algorithms

Enforcing randomness instead of hoping for it

What if we don't know the input distribution? We can use a randomized algorithm. Instead of assuming the candidates arrive randomly, we ask the agency for the list of n candidates in advance, and we randomly permute the list before interviewing them.

By taking control of the randomization, the algorithm's performance no longer depends on the specific input arrangement. Even the worst input will be shuffled into a random order. We call this the expected running time.

RANDOMLY-PERMUTE(A, n)
1  for i = 1 to n
2      swap A[i] with A[RANDOM(i, n)]
Detailed Proof

Proof of RANDOMLY-PERMUTE Correctness

Loop invariant: Just prior to the i-th iteration of the for loop, for each possible (i - 1)-permutation of the n elements, the subarray A[1 : i - 1] contains this permutation with probability (n - i + 1)! / n!.

  • Initialization: Before the first iteration, i = 1. The subarray A[1:0] is empty, and a 0-permutation has no elements. The probability is n! / n! = 1. The invariant holds.
  • Maintenance: During the i-th iteration, we want to form an i-permutation ⟨x₁, ..., xᵢ⟩. By the loop invariant, the probability that the first i - 1 elements are ⟨x₁, ..., xᵢ₋₁⟩ is (n - i + 1)! / n!. The algorithm then chooses xᵢ randomly from the remaining n - i + 1 elements. Thus, the probability of selecting exactly xᵢ is 1 / (n - i + 1).
    Multiplying these gives: ((n - i + 1)! / n!) * (1 / (n - i + 1)) = (n - i)! / n!. The invariant holds for the next iteration.
  • Termination: When the loop terminates, i = n + 1. The probability that A[1:n] contains a specific n-permutation is (n - (n + 1) + 1)! / n! = 0! / n! = 1 / n!. Thus, it produces a uniform random permutation.

4Birthday Paradox & More

Classic probabilistic examples

Detailed Example

The Birthday Paradox

How many people must be in a room before there's a 50% chance two of them share a birthday? The answer is surprisingly few: 23 people.

Proof using Indicator Random Variables:
Let X_ij = 1 if person i and j share a birthday (probability 1/n, where n=365).
The expected number of pairs sharing a birthday is E[X] = Σ_{i=1}^{k-1} Σ_{j=i+1}^{k} E[X_ij] = k(k-1)/(2n).
Setting this expected value to 1 and solving for k yields approx 28 people, but the 50% probability threshold is crossed at just 23 because the exact probability of all birthdays being distinct is 1 × (1 - 1/n) × (1 - 2/n) × ... × (1 - (k-1)/n). Using the inequality 1 + x ≤ e^x, this is bounded by e^{-k(k-1)/2n}. Setting this to 1/2 yields k ≈ 23.

Detailed Example

Balls and Bins (Coupon Collector's Problem)

Tossing identical balls into b bins independently. Probability of landing in a specific bin is 1/b.

  • Expected balls in a bin: n/b (Binomial distribution).
  • Tosses until a given bin gets a ball: b (Geometric distribution).
  • Tosses until EVERY bin gets a ball: Let nᵢ be the number of tosses in the i-th stage (getting a hit in an empty bin). The probability of success is (b - i + 1) / b. The expected number of tosses for this stage is b / (b - i + 1).
    Summing over all stages: E[n] = Σ_{i=1}^{b} (b / (b - i + 1)) = b Σ_{i=1}^{b} (1/i) = b(ln b + O(1)).
Detailed Example

Streaks of Coin Flips

If you flip a coin n times, what is the longest streak of consecutive heads you expect to see? The expected length is Θ(lg n).

Upper bound O(lg n): The probability that a streak of k = 2⌈lg n⌉ heads starts at a given position is 1 / 2^(2⌈lg n⌉) ≤ 1/n². Using Boole's inequality, the probability it starts anywhere is at most n(1/n²) = 1/n. The expected length is thus tightly bounded by O(lg n).

Lower bound Ω(lg n): If we partition the flips into blocks of size s = ⌊(lg n)/2⌋, the probability a block is NOT all heads is 1 - 1/√n. The probability that NONE of the blocks are all heads is (1 - 1/√n)^(n/s) ≤ e^{-(2n/lg n)/√n} = O(1/n). Thus, with high probability, at least one block is all heads, yielding an expected length of Ω(lg n).
