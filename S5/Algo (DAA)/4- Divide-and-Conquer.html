Module 4 — Divide-and-Conquer

1Matrix Multiplication

A straightforward approach vs Divide-and-Conquer

Multiplying two n × n matrices A and B gives an n × n matrix C where each element c_ij is the sum of n pairwise products.

The standard triply nested for loop takes Θ(n³) time because there are three loops, each running exactly n times.

Divide-and-Conquer Matrix Multiplication

We can divide each n × n matrix into four n/2 × n/2 submatrices. Computing C then requires eight multiplications of n/2 × n/2 matrices, and four additions.

C₁₁ = A₁₁B₁₁ + A₁₂B₂₁
C₁₂ = A₁₁B₁₂ + A₁₂B₂₂
C₂₁ = A₂₁B₁₁ + A₂₂B₂₁
C₂₂ = A₂₁B₁₂ + A₂₂B₂₂

T(n) = 8T(n/2) + Θ(n²)

By solving this recurrence, we find that the running time is still Θ(n³). It doesn't beat the straightforward method.

2Strassen's Algorithm

Breaking the Θ(n³) barrier

In 1969, Volker Strassen discovered an algorithm that reduces the bushiness of the recursion tree. Instead of performing 8 recursive matrix multiplications, his algorithm performs only 7.

Detailed Formulation

Strassen's 4 Steps

Step 1: Partition the matrices (takes Θ(1) time via index calculation).

Step 2: Create 10 matrices S₁ to S₁₀ using additions and subtractions (takes Θ(n²) time):
S₁ = B₁₂ - B₂₂
S₂ = A₁₁ + A₁₂
S₃ = A₂₁ + A₂₂
S₄ = B₂₁ - B₁₁
S₅ = A₁₁ + A₂₂
S₆ = B₁₁ + B₂₂
S₇ = A₁₂ - A₂₂
S₈ = B₂₁ + B₂₂
S₉ = A₁₁ - A₂₁
S₁₀ = B₁₁ + B₁₂

Step 3: Recursively compute 7 matrix products P₁ to P₇ (takes 7T(n/2) time):
P₁ = A₁₁ · S₁
P₂ = S₂ · B₂₂
P₃ = S₃ · B₁₁
P₄ = A₂₂ · S₄
P₅ = S₅ · S₆
P₆ = S₇ · S₈
P₇ = S₉ · S₁₀

Step 4: Compute the final C submatrices using additions and subtractions of the P matrices (takes Θ(n²) time):
C₁₁ = P₅ + P₄ - P₂ + P₆
C₁₂ = P₁ + P₂
C₂₁ = P₃ + P₄
C₂₂ = P₅ + P₁ - P₃ - P₇

The recurrence becomes:

T(n) = 7T(n/2) + Θ(n²)

Using the Master Theorem, this recurrence yields a running time of Θ(n^(lg 7)) ≈ O(n²·⁸¹).

3Substitution Method

Proving recurrences using induction

The substitution method for solving recurrences entails two steps:

  1. Guess the form of the solution.
  2. Use mathematical induction to find the constants and show that the solution works.
Detailed Proof

Solving T(n) = 2T(⌊n/2⌋) + n

Guess: T(n) = O(n log n). We need to prove T(n) ≤ cn log n for some constant c.

Assume it holds for ⌊n/2⌋: T(⌊n/2⌋) ≤ c ⌊n/2⌋ log(⌊n/2⌋).

Substitute into the recurrence:
T(n) ≤ 2(c ⌊n/2⌋ log(⌊n/2⌋)) + n
≤ cn log(n/2) + n
= cn log n - cn log 2 + n
= cn log n - cn + n
≤ cn log n (as long as c ≥ 1).

Trick of the Trade: Subtracting a lower-order term

Sometimes your guess is asymptotically right, but the induction fails. For example, solving T(n) = 2T(n/2) + 1.

If you guess T(n) ≤ cn, substituting yields T(n) ≤ cn + 1, which does NOT imply T(n) ≤ cn. The math fails.

The Fix: Subtract a lower-order term. Guess T(n) ≤ cn - d where d > 0.

Substitute: T(n) ≤ 2(c(n/2) - d) + 1 = cn - 2d + 1.

We want this to be ≤ cn - d. So we need cn - 2d + 1 ≤ cn - d, which simplifies to d ≥ 1. The math now works beautifully!

4Recursion-Tree Method

Visualizing the cost of recursive calls

A recursion tree represents the cost of the subproblems at each level of the recursion. It is highly effective for generating a good guess to use in the substitution method.

Detailed Example

Solving T(n) = 3T(n/4) + cn²

  • Root Level: The root cost is cn².
  • Level 1: There are 3 nodes. Each has size n/4, so each costs c(n/4)² = cn²/16. The total for this level is 3 × cn²/16 = (3/16)cn².
  • Level i: The size of each node is n/4ⁱ. There are 3ⁱ nodes. The total cost at level i is 3ⁱ × c(n/4ⁱ)² = (3/16)ⁱcn².

Because 3/16 < 1, the costs decrease geometrically at each level. The total cost of all levels is bounded by the sum of an infinite decreasing geometric series:

T(n) ≤ Σ_{i=0}^{∞} (3/16)ⁱcn² = (1 / (1 - 3/16)) cn² = (16/13) cn².

Thus, the overall time is exactly bounded by the root, yielding O(n²).

5The Master Method

A cookbook approach for standard recurrences

The master method provides bounds for recurrences of the form:

T(n) = aT(n/b) + f(n)

Where a ≥ 1, b > 1, and f(n) is the driving function (cost of dividing/combining). We compare f(n) with the watershed function n^(log_b a).

The Three Cases
  1. Leaves dominate: If f(n) grows polynomially slower than the watershed function, i.e., f(n) = O(n^(log_b a - ε)) for some ε > 0, then T(n) = Θ(n^(log_b a)).
  2. Costs are evenly distributed: If f(n) and the watershed function grow at the same asymptotic rate, i.e., f(n) = Θ(n^(log_b a) · logᵏ n), then T(n) = Θ(n^(log_b a) · logᵏ⁺¹ n).
  3. Root dominates: If f(n) grows polynomially faster than the watershed function, i.e., f(n) = Ω(n^(log_b a + ε)) AND satisfies the regularity condition af(n/b) ≤ cf(n) for some c < 1, then T(n) = Θ(f(n)).
Examples
  • Case 1 (Strassen's): T(n) = 7T(n/2) + n².
    Here a=7, b=2, watershed is n^(log₂ 7) ≈ n²·⁸¹.
    f(n) = n² is polynomially smaller than the watershed (by ε ≈ 0.81). Thus T(n) = Θ(n^(log₂ 7)).
  • Case 2 (Merge Sort): T(n) = 2T(n/2) + n.
    Here a=2, b=2, watershed is n^(log₂ 2) = n¹.
    f(n) = n¹, which exactly matches the watershed. Thus T(n) = Θ(n log n).
  • Case 3: T(n) = 3T(n/4) + n log n.
    Here a=3, b=4, watershed is n^(log₄ 3) ≈ n⁰·⁷⁹³.
    f(n) = n log n grows polynomially faster than the watershed. Checking regularity: 3(n/4)log(n/4) ≤ (3/4)n log n. Since 3/4 < 1, it holds. Thus T(n) = Θ(n log n).

6Exercises & Solutions

Test your understanding

Practice Q1: Solve T(n) = 2T(n/4) + 1

Answer:
Using the master method: a = 2, b = 4.
Watershed function: n^(log₄ 2) = n^(0.5) = √n.
f(n) = 1, which is O(n^(0.5 - ε)) for ε = 0.5. This is Case 1.
Solution: T(n) = Θ(√n).

Practice Q2: Solve T(n) = 2T(n/4) + √n

Answer:
Using the master method: a = 2, b = 4.
Watershed function: n^(log₄ 2) = √n.
f(n) = √n. The driving function exactly matches the watershed function. This is Case 2 (with k=0).
Solution: T(n) = Θ(√n log n).

Practice Q3: Solve T(n) = 2T(n/4) + n

Answer:
Using the master method: a = 2, b = 4.
Watershed function: n^(log₄ 2) = √n.
f(n) = n, which is Ω(n^(0.5 + ε)) for ε = 0.5. Checking regularity: 2(n/4) ≤ cn, so (1/2)n ≤ cn holds for c = 1/2 < 1. This is Case 3.
Solution: T(n) = Θ(n).
