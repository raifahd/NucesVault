Visualizing Data: Mapping Aesthetics & Coordinate Systems

📖
Core Reference: Claus O. Wilke, Fundamentals of Data Visualization (O'Reilly, 2019), Ch 2 (Mapping Data onto Aesthetics) & Ch 3 (Coordinate Systems and Axes).

1Aesthetics and Types of Data

The grammar of graphics: mapping raw data values into quantifiable visual channels.

All data visualizations share a unified foundation: they systematically map data values into quantifiable, visible features of graphical marks. These visual attributes are called aesthetics.

Definition
Aesthetic: A quantifiable visual property of a graphical mark (position, shape, size, color, line width, line type) varied systematically to represent data.
Intuitive translation: The visual dial you twist (making a dot higher, larger, or darker) to represent data values.

🎨 Aesthetic Channels & Data Capabilities

Aesthetics are categorized by whether they support continuous gradients or are strictly discrete.

1. Position (x, y) Continuous & Discrete

Horizontal (x) and vertical (y) placement. Rank 1 in human perceptual accuracy.

2. Size / Area Continuous & Discrete

Bubble area/length. Encodes magnitudes (population, GDP, weight).

3. Color (Hue & Lum) Continuous & Discrete

Luminance/saturation for continuous metrics; distinct hues for categories.

4. Line Width Continuous & Discrete

Thickness of paths. Useful for network traffic or flow volume.

5. Shape Discrete Only

Circles, triangles, squares. Cannot represent continuous data (no intermediate shapes).

6. Line Type Discrete Only

Solid, dashed, dotted. Strictly categorical.

Quiz Trap: Continuous vs. Discrete Aesthetics
Shape and Line Type can NEVER represent continuous quantitative data! Continuous data requires infinitely fine intermediates (e.g., between 4.1 and 4.2). No intermediate shape exists halfway between a square and a triangle.

Variable Types Taxonomy

Quantitative (Numerical)

  • Continuous: Real numbers with infinite intermediates (e.g. Height: 1.75m, Temp: 72.4°F, Duration: 50.51s).
  • Discrete: Countable units where fractional values do not exist in dataset (e.g. Persons: 1, 2, 3; Shoe sizes: 8.5, 9.0).

Qualitative (Categorical)

  • Unordered Factor (Nominal): Discrete categories with no inherent ranking (e.g. dog, cat, fish; Chicago, Houston).
  • Ordered Factor (Ordinal): Discrete categories with strict hierarchy (e.g. poor < fair < good; Jan, Feb, Mar).

Date / Time

  • Specific Timestamps: Jan 5 2024, 08:30 AM (continuous elapsed time or discrete calendar day).
  • Cyclical Dates: Repeating periods without year (e.g. July 4th, Month 1-12).

Text Data

  • Free-Form Text: Open-ended text labels or unstructured prose. Treated as qualitative labels.
Definition
Factor and Levels: A qualitative categorical variable is called a factor, and each unique category within it is a level.
Example: Variable `City` is a factor; its levels are `['Chicago', 'San Diego', 'Houston', 'Death Valley']`.

Variables containing digits (e.g. Station ID USW00014819, Zip Code 90210, Student ID) are unordered factors because arithmetic (averaging, addition) is meaningless.
Practice Questions for Topic 1
Easy: Can you map continuous salary values to the "Shape" aesthetic?

Answer: No. Salary is continuous, while shape is strictly discrete with no intermediate geometric states.

Medium: What distinguishes an Ordered Factor from an Unordered Factor?

Answer: An ordered factor has an intrinsic ranking (e.g. poor < fair < good) that must be preserved on the visual axis. Unordered factors have no ranking and can be sorted arbitrarily.

Hard: Can fractional numbers (e.g. 0.5, 1.0, 1.5) be classified as Quantitative Discrete?

Answer: Yes. If intermediate fractions cannot exist in the dataset (e.g. half-size shoe measurements), the numbers represent discrete units.

Key Takeaways: Aesthetics & Data Types

  • Continuous Aesthetics: Position, size, color luminance, and line width.
  • Discrete-Only Aesthetics: Shape and line type (never use for continuous data).
  • Factors & Levels: Categorical variables are factors; unique values are levels. Ordered factors demand strict visual sequencing.

2Scales and Multi-Aesthetic Data Mapping

How scales create unambiguous 1-to-1 mappings and encode high-dimensional data.

A scale is the mathematical bridge linking data values to aesthetic values.

Definition
Scale: A formal mapping function from data space to aesthetic space.
The One-to-One Rule: Scales must be strictly bijective (one-to-one and invertible). Each data value maps to exactly one aesthetic value, and vice-versa. Non-invertible scales cause visual ambiguity.

🔄 One-to-One Scale Mapping Architecture

A scale takes input from the Data Domain and projects it onto the Visual Aesthetic Range.

Scientific Rule
Stone-Albers Szafir Area Saliency Rule (2014): When continuous quantitative data is mapped to color, graphical elements must have sufficiently large visual areas (like tiles) for the human visual cortex to distinguish shade differences. Thin lines fail.

Multi-Scale Mapping: Encoding 5 Variables (Wilke Fig 2-5)

Multiple scales can be layered onto a single scatter plot:

  • X Position: Engine Displacement (Quantitative Continuous)
  • Y Position: Fuel Efficiency / MPG (Quantitative Continuous)
  • Color: Horsepower / Power (Quantitative Continuous)
  • Size (Area): Car Weight (Quantitative Continuous)
  • Shape: Cylinders: 4, 6, 8 (Qualitative Ordered / Discrete Count)
Ordering Unordered Factors
On discrete axes, unordered factors should be sorted intentionally by a meaningful metric (e.g. coldest to hottest) rather than left alphabetical.
Practice Questions for Topic 2
Easy: Why must visual scales be one-to-one?

Answer: To prevent ambiguity; every data value must map to a unique visual mark, and vice-versa.

Medium: Why did Wilke use square tiles instead of lines in the temperature heatmap?

Answer: Per Stone et al. (2014), continuous color requires large surface area for human eyes to perceive subtle differences in shade.

Hard: Can Weight be mapped to Shape in the 5-variable car plot?

Answer: No. Weight is continuous, and shape cannot represent continuous data.

Key Takeaways: Scales & Multi-Aesthetic Mapping

  • 1-to-1 Mapping: Scales must be bijective functions to avoid ambiguous decoding.
  • Area Saliency for Color: Continuous color requires large spatial blocks (heatmaps) rather than thin lines.
  • Multi-Scale Stacking: Up to 5 variables can be encoded (x, y, color, size, shape), but shape must remain discrete.

3Cartesian Coordinates, Units & Aspect Ratios

Geometric arrangements, aspect ratio perception, and invariance under linear transformations.

Definition
Coordinate System: A set of position scales and their relative geometric arrangement.
Cartesian Coordinates: Two straight axes ($x, y$) meeting orthogonally at 90°, with grid lines marking discrete steps in data units.

Aspect Ratio Dynamics

When axes measure different units (e.g. °F vs. Months), there is no physically mandated aspect ratio. Stretching or compressing changes perceived rate of change:

📐 Aspect Ratio Perception (Wilke Figure 3-2)

(a) Tall & Narrow

Emphasizes vertical swings. Slopes appear steep.

(b) Balanced (Banked ~45°)

Natural proportional rate of change (Cleveland's principle).

(c) Short & Wide

De-emphasizes vertical swings. Curve appears flat.

The Same-Units Rule: 1:1 Aspect Ratio Mandatory!
When both axes measure the same physical quantity in the same units (e.g. Houston Temp vs. San Diego Temp in °F), the grid must form perfect squares (1:1 aspect ratio). Otherwise, the 45° diagonal line of equality ($y = x$) rotates, distorting comparison.

Invariance Under Linear Transformations

Converting units is a linear transformation: $y' = a \cdot y + b$ (e.g. $C = \frac{5}{9}(F - 32)$).

Core Principle
Linear Invariance: Cartesian coordinate systems are strictly invariant under linear transformations. Changing units (°F to °C) shifts grid values, but the relative visual scatter of points and slopes remains 100% identical.

🌡️ Linear Transformation Invariance (Wilke Figure 3-3)

Celsius (°C)

Identical visual geometry; only axis numbers shift.

Practice Questions for Topic 3
Easy: What is an orthogonal coordinate system?

Answer: A system where axes meet at right angles (90 degrees).

Medium: When plotting weight (lbs) vs. height (inches), must the aspect ratio be 1:1?

Answer: No. Pounds and inches are different physical units. Aspect ratio can be adjusted freely.

Hard: Why does converting miles to km leave a Cartesian scatter plot unchanged?

Answer: Converting miles to km is a linear transformation ($km = 1.609 \times miles$). Cartesian coordinates are invariant under linear transformations.

Key Takeaways: Cartesian Coordinates

  • Different Units: Aspect ratio can be stretched/compressed (Cleveland recommends banking slopes to ~45°).
  • Same Units: Requires a strict 1:1 square grid to avoid angular distortion.
  • Linear Invariance: Linear conversions ($y' = ay + b$) preserve exact data geometry.

4Nonlinear Axes: Logarithmic and Square-Root Scales

Handling multi-order magnitudes, ratio symmetry, and zero boundaries.

Linear scales fail when data spans multiple orders of magnitude or represents multiplicative ratios.

Definition
Logarithmic Scale (Log Scale): A nonlinear position scale that is linear in multiplication. Equal physical distance corresponds to multiplying by a fixed constant factor ($\times 10$ or $\times 2$).

📏 Linear vs. Logarithmic Spacing (Wilke Figure 3-4)

(a) Linear Scale (Additive: +25 per step) → Severe clustering near 0!
(b) Logarithmic Scale (Multiplicative: ×10 per major interval) → Even geometric steps!

The 3.16 Rule: On a log-10 scale, the halfway point between 1 ($10^0$) and 10 ($10^1$) is $10^{0.5} = \sqrt{10} \approx 3.16$.

Exam Trap: Axis Labeling on Log Scales
The correct axis title on a log scale is the name of the variable (e.g. "Population"), NOT "log(Population)". Tick marks should show raw values (1, 10, 100).

Why Ratios Must Use Log Scales: Texas Counties Case Study

When dividing by a median, 1.0 is the natural neutral midpoint.

  • On a linear scale, a 10× increase (1 to 10) takes 9 units, but a 10× decrease (1 to 0.1) takes only 0.9 units (10× visual distortion!).
  • On a log scale, doubling ($\times 2$) and halving ($\div 2$) are visually symmetric around 1.0.

🤠 Texas County Population Ratios (Wilke Figures 3-5 & 3-6)

❌ Linear Scale: Misleading Asymmetry
✅ Log Scale: Perfect Symmetry
The Zero Barrier
Zero can NEVER appear on a log scale: $\log(0) = -\infty$. Reaching zero requires infinite divisions.

The Square-Root Scale: Properties & Flaws

Square-root scales ($\sqrt{x}$) accommodate zero ($\sqrt{0} = 0$) and naturally model geographic surface areas ($\sqrt{\text{Area}} \propto \text{linear driving time}$ across a state).

⚠️ Wilke's 2 Critiques of Square-Root Scales:
  1. No Constant Step Meaning: Unit step meaning changes depending on starting value (0 to 1 adds 1; 9 to 16 adds 7).
  2. Awkward Tick Placement: Ticks placed at squares (0, 4, 25, 49) or linear intervals (10, 20, 30) are both visually awkward.
Practice Questions for Topic 4
Easy: Why is zero forbidden on a log scale?

Answer: Because $\log(0) = -\infty$.

Medium: What value is halfway between 1 and 10 on a log-10 scale?

Answer: $10^{0.5} \approx 3.16$.

Hard: Why are square-root scales used for geographic land area?

Answer: Area scales quadratically ($\text{length}^2$). Taking $\sqrt{\text{Area}}$ yields linear border-to-border extent, which correlates with driving time.

Key Takeaways: Nonlinear Axes

  • Log Scales are Multiplicative: Equal distance = fixed multiplier. Mandatory for ratios (symmetric around 1.0).
  • Zero Barrier: Never use log scales for datasets containing zeros or negative values.
  • Square-Root Trade-Off: Accommodates zero and land areas, but suffers from non-uniform steps and awkward ticks.

5Curved Coordinates and Map Projections

Polar cycles for periodic data and navigating the map projection distortion trilemma.

Definition
Polar Coordinates: Position is specified by an angle ($\theta$) and a radial distance ($r$) from the center origin.
Best For: Periodic or cyclical data where the end wraps into the beginning (days of year, 24h clock, wind direction).

🔄 Cartesian Split vs. Polar Continuity (Wilke Figure 3-10)

Cartesian: Severed Winter Continuum

Jan 1 and Dec 31 sit on opposite edges of the canvas, hiding the fact that winter weather is continuous.

Polar: Continuous Seasonal Loop

Dec 31 connects directly to Jan 1 around the circular dial.

Geospatial Map Projections & The Distortion Trilemma

Flattening the 3D spherical Earth onto a 2D surface forces a compromise among three properties: preserving area, preserving angles/shapes, and continuity.

1. Cartesian Lat/Long (Equirectangular)
Area: Severe Polar Inflation
Verdict: Not recommended for scientific maps.
2. Interrupted Goode Homolosine
Area: 100% Equal-Area
Trade-Off: Slices oceans into separate lobes.
3. Robinson Projection
Type: Compromise Projection
Verdict: Visually pleasing balance of shapes and areas.
4. Winkel Tripel Projection
Type: Compromise Projection
Verdict: Gold standard for global maps (lowest overall distortion).
Practice Questions for Topic 5
Easy: What coordinates define a point in a polar system?

Answer: Angle ($\theta$) and radial distance ($r$).

Medium: What visual defect occurs when mapping latitude and longitude to Cartesian axes?

Answer: Massive horizontal stretching near the poles (Greenland appears equal in size to Africa).

Hard: Why must choropleth thematic maps use equal-area projections?

Answer: Because viewers judge magnitude by visible surface area. Conformal projections (like Mercator) distort land areas, misrepresenting the data.

Key Takeaways: Curved & Geospatial Coordinates

  • Polar Coordinates: Natural for cyclical/periodic data (connects Dec 31 to Jan 1).
  • Projection Trilemma: You cannot flatten a 3D sphere into 2D without distorting area, angles, or continuity.
  • Key Projections: Goode Homolosine preserves true area; Robinson and Winkel Tripel minimize overall compromise distortion.

4. The 10 Deadly Exam Traps

  1. Trap 1: "Can Shape represent continuous data?" $\to$ NEVER. Discrete only.
  2. Trap 2: "Are numeric ID codes quantitative?" $\to$ No, they are qualitative unordered factors.
  3. Trap 3: "Can zero be plotted on a log scale?" $\to$ No, $\log(0) = -\infty$.
  4. Trap 4: "How should a log axis be labeled?" $\to$ With the variable name (e.g. Population), NOT log(Population).
  5. Trap 5: "What happens if a scale is not 1-to-1?" $\to$ The visualization becomes ambiguous.
  6. Trap 6: "When is a 1:1 aspect ratio mandatory?" $\to$ When both axes share the same physical unit.
  7. Trap 7: "Does °F to °C change scatter plot shape?" $\to$ No, Cartesian systems are invariant under linear transformations.
  8. Trap 8: "Why plot ratios on log scales?" $\to$ Doubling and halving are symmetric around the natural midpoint 1.0.
  9. Trap 9: "What is the flaw of square-root scales?" $\to$ Step size has no uniform meaning across the scale.
  10. Trap 10: "Why avoid Mercator for choropleth maps?" $\to$ Severe high-latitude area distortion misrepresents data magnitude.
