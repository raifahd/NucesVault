Lab 7 — Local Search: Hill Climbing & Genetic Algorithms

1Hill Climbing — The Concept

A local search algorithm that always moves to the best neighbouring state

Hill Climbing is like being in a foggy mountain range and always stepping uphill. You can't see the whole landscape — you just evaluate your immediate neighbours and move to the best one. When no neighbour is better, you stop. You might end up at a local peak, not the global summit.

Definition
Hill Climbing: A local search algorithm that iteratively moves to the best neighbouring state. It maintains only the current state in memory — not the full path. Useful for optimization problems where we want the best state, not necessarily the path to it.
State Landscape — Hill Climbing can get stuck

        /\
       /  \
      /    \    ← Local Maximum
     /      \  /\
    /        \/  \
   /              \

Local Maximum
Better than all neighbours but NOT the best overall
Plateau
Flat area — all neighbours equal, nowhere to go
Ridge
A narrow peak hard to follow with greedy steps

Key Concepts

ConceptWhat it meansExample
StateA candidate solutionCurrent position on a landscape graph
NeighbourA state reachable from currentAdjacent nodes in the graph
Evaluation Function f(state)How good a state is (higher = better)The value at that state

Hill Climbing Steps

  1. Choose an initial state
  2. Evaluate the current state
  3. Generate all neighbour states
  4. Pick the best neighbour
  5. If best neighbour is better than current → move to it, repeat from step 2
  6. If no better neighbour exists → STOP (local optimum reached)

Key Takeaways

  • Hill Climbing only stores the current state — very memory efficient
  • Stops when no neighbour improves — may be local max, not global max
  • Good for large state spaces where storing all paths is impractical
  • Evaluation function: higher value = better state

2Variants and Limitations

Three flavours of hill climbing and how to escape its pitfalls

Simple Hill Climbing

Checks neighbours one by one. Moves to the first better neighbour found. Fast per step but may miss better options.

Steepest-Ascent HC

Evaluates ALL neighbours and picks the best one. More thorough but more computation per step.

Stochastic HC

Picks a random improving neighbour. Avoids always following the same path — can escape some traps.

Techniques to Escape Local Maxima

TechniqueHow it works
Random RestartRun hill climbing multiple times from random starting states, keep the best result
Sideways MovesAllow moving to a neighbour of equal value (to cross plateaus)
Stochastic Hill ClimbingPick a random improving neighbour instead of always the best — introduces randomness
Common Mistake
Students confuse hill climbing with BFS/DFS. Hill Climbing does NOT maintain a frontier or visited set. It only keeps track of the current state. It can revisit states. It is NOT guaranteed to find the global optimum.
Exam Hint
Questions often ask "Why does hill climbing stop at X?" — The answer is always: all neighbours of X have equal or lower value, so there's no improving move. This is either a local maximum, plateau, or ridge.

3Implementation Examples

Graph-based hill climbing with state landscape

Example

Problem 1: Hill Climbing on State Landscape

# State landscape: state → list of reachable neighbours
landscape = {
    1: [2, 3],
    2: [4, 5],
    3: [5],
    4: [7],
    5: [6],
    6: [8],
    7: [],    # dead end
    8: []     # dead end (highest value!)
}
# The state number IS the evaluation value:
# state 8 is better than state 7

def hill_climbing(landscape, start):
    current = start
    visited = [current]
    print(f"Start: {current}")

    while True:
        neighbours = landscape[current]

        if not neighbours:
            print(f"No neighbours — stuck at {current}")
            break

        # Find best neighbour (highest value = best state here)
        best_neighbour = max(neighbours)

        if best_neighbour > current:
            print(f"  Moving: {current} → {best_neighbour}")
            current = best_neighbour
            visited.append(current)
        else:
            print(f"  No improvement — local max at {current}")
            break

    print(f"Path: {visited}")
    print(f"Final local maximum: {current}")
    return current

hill_climbing(landscape, start=1)
# Start: 1
# Moving: 1 → 3  (3 > 2, so pick 3 as best of [2,3])
# Moving: 3 → 5
# Moving: 5 → 6
# Moving: 6 → 8
# Final local maximum: 8  ← this happens to be global max!

Problem 2: Random Restart Hill Climbing

import random

def hill_climb_once(landscape, start):
    current = start
    while True:
        neighbours = landscape.get(current, [])
        if not neighbours: break
        best = max(neighbours)
        if best > current:
            current = best
        else:
            break
    return current

def random_restart_hc(landscape, num_restarts=5):
    states = list(landscape.keys())
    best_overall = None
    results = []

    for run in range(num_restarts):
        start = random.choice(states)
        local_max = hill_climb_once(landscape, start)
        results.append((start, local_max))
        print(f"Run {run+1}: start={start}, local max={local_max}")

        if best_overall is None or local_max > best_overall:
            best_overall = local_max

    print(f"\nBest solution found: {best_overall}")
    print(f"Total restarts: {num_restarts}")
    return best_overall

landscape = {1:[2,3],2:[4,5],3:[5],4:[7],5:[6],6:[8],7:[],8:[]}
random_restart_hc(landscape, num_restarts=5)
Pro Tip
Random Restart is the simplest fix for local maxima. More restarts = higher chance of finding the global optimum. The trade-off is time (each restart is a full hill climb run). For the exam: always say "Random restart can find a better solution because different starting points may lead to different local maxima."

4Function Optimization with Hill Climbing

Finding the maximum of a mathematical function step by step

Hill Climbing can optimize continuous or discrete mathematical functions. The "state" is a value of x, "neighbours" are x+1 and x-1, and the evaluation function is f(x).

Example

Problem 3: Maximize f(x) = -(x-3)² + 9

def f(x):
    return -(x - 3)**2 + 9
    # Maximum at x=3, f(3)=9
    # f(0)=0, f(1)=5, f(2)=8, f(3)=9, f(4)=8, ...

def hill_climbing_function(f, start_x):
    x = start_x
    print(f"Start: x={x}, f(x)={f(x)}")

    while True:
        # Generate neighbours: x-1 and x+1
        neighbours = [x - 1, x + 1]

        # Evaluate all neighbours
        best_x = max(neighbours, key=f)  # pick neighbour with best f value

        print(f"  Current: x={x} f={f(x)} | Neighbours: {[f(n) for n in neighbours]}")

        if f(best_x) > f(x):
            print(f"  → Moving to x={best_x}")
            x = best_x
        else:
            print(f"  → No improvement. Local max at x={x}")
            break

    print(f"\nFinal: x={x}, f(x)={f(x)}")
    return x, f(x)

hill_climbing_function(f, start_x=0)
# x=0: neighbours x=-1(f=-7), x=1(f=5) → move to 1
# x=1: neighbours x=0(f=0), x=2(f=8) → move to 2
# x=2: neighbours x=1(f=5), x=3(f=9) → move to 3
# x=3: neighbours x=2(f=8), x=4(f=8) → no improvement
# Final: x=3, f(x)=9  ← GLOBAL MAX!

Problem 4: Stochastic Hill Climbing — f(x) = -(x-4)² + 16

import random

def f2(x):
    return -(x - 4)**2 + 16
    # Maximum at x=4, f(4)=16

def stochastic_hill_climb(f, x_range, num_runs=5):
    best_x, best_val = None, float('-inf')

    for run in range(num_runs):
        # Random starting x within range
        x = random.randint(*x_range)
        path = [x]
        print(f"\nRun {run+1}: start x={x}, f(x)={f(x)}")

        while True:
            neighbours = [x - 1, x + 1]
            # Filter: only keep IMPROVING neighbours
            improving = [n for n in neighbours if f(n) > f(x) and x_range[0] <= n <= x_range[1]]

            if not improving:
                print(f"  Stuck at x={x}, f={f(x)}")
                break

            # STOCHASTIC: pick a RANDOM improving neighbour
            x = random.choice(improving)
            path.append(x)

        print(f"  Path: {path}, Final: x={x}, f={f(x)}")
        if f(x) > best_val:
            best_val = f(x); best_x = x

    print(f"\nBest across all runs: x={best_x}, f={best_val}")

stochastic_hill_climb(f2, x_range=(0, 8), num_runs=5)

Lab 7 Complete Summary

  • Hill Climbing = greedy local search — only moves to improving neighbours
  • Stops at local maximum (no better neighbour) — may not be global max
  • 3 variants: Simple (first better), Steepest-Ascent (best of all), Stochastic (random improving)
  • 3 pitfalls: Local Maximum, Plateau, Ridge
  • Fix: Random Restart — run multiple times, keep best result
  • For functions: state=x, neighbours=x±1, eval=f(x)
Practice Questions
Easy: Why does hill climbing stop? What is a local maximum?

Answer: Hill climbing stops when no neighbour has a higher value than the current state. A local maximum is a state that is better than all its immediate neighbours but may not be the best state overall (global maximum). Hill climbing gets stuck here because it never makes moves that decrease the value.

Medium: Why can Random Restart produce better solutions?

Answer: Different starting states lead to different local maxima. By running hill climbing multiple times from randomly chosen starting states, we explore different regions of the state space. The probability of at least one run finding the global maximum increases with the number of restarts.

landscape = {1:[2,3],2:[4,5],3:[5],4:[7],5:[6],6:[8],7:[],8:[]}

def steepest_ascent_hc(landscape, start):
    current = start
    print(f"Steepest Ascent Hill Climbing")
    print(f"Start: {current}")

    while True:
        neighbours = landscape.get(current, [])
        if not neighbours:
            print(f"No neighbours — stuck at {current}"); break

        # STEEPEST-ASCENT: evaluate ALL neighbours first
        print(f"  Evaluating ALL neighbours of {current}: {neighbours}")
        best_n = max(neighbours)   # best among all

        if best_n > current:
            print(f"  Best neighbour: {best_n} > {current} → MOVE")
            current = best_n
        else:
            print(f"  No neighbour better than {current} → STOP")
            break

    print(f"Local maximum: {current}")
    return current

5Genetic Algorithms (GA) — Evolutionary Search & Selection

Global stochastic optimization inspired by biological natural selection and genetics

Where Hill Climbing keeps a single state and moves to immediate neighbours (often getting trapped in local peaks), a Genetic Algorithm (GA) maintains an entire population of candidate solutions simultaneously. Solutions reproduce based on their fitness, pass traits forward, and explore new territory via mutation.

Core Anatomy of a Genetic Algorithm
  • Individual / Chromosome: A candidate solution (e.g. a scalar number x, bitstring 01101, or array of genes).
  • Population: A collection of N individuals evaluated together across iterations (generations).
  • Fitness Function f(x): The objective function measuring how "good" an individual is. Higher fitness = greater chance of survival.
  • Selection: Choosing which individuals survive and reproduce to form the next generation.
  • Mutation: Adding random perturbation (e.g. x = x + random.uniform(-1, 1)) with probability p_m to maintain diversity and prevent stagnation.

Selection Strategies: Ranking vs Roulette Wheel

The choice of selection method determines how the algorithm balances exploitation (focusing on currently best solutions) and exploration (preserving diverse solutions to discover new optima):

Selection Method How It Works Advantages Key Weakness / Exam Trap
Ranking Selection Sort individuals by fitness from 1 to N. Selection depends strictly on rank (e.g. top 50%), completely ignoring numerical fitness differences. Prevents premature convergence! A super-fit individual cannot monopolize reproduction because rank difference is fixed. Maintains stable selection pressure. Slower convergence rate when fitness differences are genuinely informative and large.
Roulette Wheel (Fitness-Proportionate) Each individual gets a slice of a roulette wheel proportional to its fitness: P(i) = f(i) / ∑ f(j). Random spin selects individuals. Directly rewards higher quality proportionally. Converges very quickly toward high-fitness regions. Premature Convergence Risk: If one early individual has high fitness ("super-individual"), it dominates the wheel, clones itself everywhere, and population loses all diversity. Also requires strictly positive fitness values!
Tournament Selection Pick k individuals at random from population; the one with highest fitness wins the tournament and is selected. No sorting needed, easily parallelizable, adjustable selection pressure via tournament size k. Requires tuning tournament size k.

Full Implementation: Optimizing f(x) = -x² + 10x + 5

Let us maximize the function $f(x) = -x^2 + 10x + 5$ (which has a global maximum at $x=5$ where $f(5)=30$). We implement both Ranking Selection and Roulette Wheel Selection with controlled mutation:

Complete Python GA Implementation (Exam Standard)
import random

def fitness_func(x):
    """Objective: Maximize f(x) = -x^2 + 10x + 5. Peak is at x=5, f(5)=30."""
    return -(x**2) + 10 * x + 5

# ── 1. GA WITH RANKING SELECTION ──────────────────────────────────
def ga_ranking(pop_size=10, generations=10, mutation_rate=0.2):
    print("=" * 60)
    print("GA EXPERIMENT 1: RANKING SELECTION (TOP 50% SURVIVAL)")
    print("=" * 60)
    
    # Initialize random population in range [-5, 15]
    random.seed(42)
    population = [random.uniform(-5, 15) for _ in range(pop_size)]

    for gen in range(1, generations + 1):
        # Calculate fitness for each individual
        fitness_values = [fitness_func(ind) for ind in population]

        # Rank individuals: highest fitness -> Rank 1 (index 0)
        ranked = sorted(zip(population, fitness_values), key=lambda item: item[1], reverse=True)
        
        best_individual, best_fitness = ranked[0]
        print(f"Gen {gen:2d} | Best x: {best_individual:7.4f} | Fitness: {best_fitness:7.4f}")

        # Select top 50% individuals based strictly on ranking
        top_half = [ind for ind, fit in ranked[:pop_size // 2]]

        # Reproduce: duplicate top individuals to restore full population size
        new_population = []
        while len(new_population) < pop_size:
            new_population.extend(top_half[:pop_size - len(new_population)])

        # Apply controlled mutation: x = x + uniform(-1, 1) with 20% probability
        for i in range(len(new_population)):
            if random.random() < mutation_rate:
                mutation_offset = random.uniform(-1, 1)
                new_population[i] = new_population[i] + mutation_offset

        population = new_population

    # Final best evaluation
    final_ranked = sorted(zip(population, [fitness_func(x) for x in population]), key=lambda item: item[1], reverse=True)
    best_x, max_fit = final_ranked[0]
    print(f"\nFinal Best Solution after {generations} gens: x = {best_x:.4f}")
    print(f"Maximum Fitness Achieved: {max_fit:.4f} (Theoretical max = 30.0000 at x=5)")
    return best_x, max_fit

# ── 2. GA WITH ROULETTE WHEEL SELECTION ───────────────────────────
def ga_roulette(pop_size=10, generations=10, mutation_rate=0.2):
    print("\n" + "=" * 60)
    print("GA EXPERIMENT 2: ROULETTE WHEEL (FITNESS-PROPORTIONATE)")
    print("=" * 60)
    
    random.seed(42)
    population = [random.uniform(-5, 15) for _ in range(pop_size)]

    for gen in range(1, generations + 1):
        fitness_values = [fitness_func(ind) for ind in population]
        
        # Best individual of current generation
        best_idx = max(range(pop_size), key=lambda i: fitness_values[i])
        print(f"Gen {gen:2d} | Best x: {population[best_idx]:7.4f} | Fitness: {fitness_values[best_idx]:7.4f}")

        # Roulette wheel requires strictly positive values: shift if any <= 0
        min_fit = min(fitness_values)
        shifted_fitness = [fit - min_fit + 1e-4 for fit in fitness_values] if min_fit <= 0 else fitness_values
        total_fit = sum(shifted_fitness)
        probabilities = [sf / total_fit for sf in shifted_fitness]

        # Select individuals via cumulative roulette wheel spins
        selected = []
        for _ in range(pop_size // 2):
            r = random.random()
            cumulative = 0.0
            for idx, prob in enumerate(probabilities):
                cumulative += prob
                if r <= cumulative:
                    selected.append(population[idx])
                    break
            else:
                selected.append(population[-1])

        # Restore population size
        new_population = []
        while len(new_population) < pop_size:
            new_population.extend(selected[:pop_size - len(new_population)])

        # Controlled mutation
        for i in range(len(new_population)):
            if random.random() < mutation_rate:
                new_population[i] = new_population[i] + random.uniform(-1, 1)

        population = new_population

    final_fitness = [fitness_func(x) for x in population]
    best_final_idx = max(range(pop_size), key=lambda i: final_fitness[i])
    print(f"\nFinal Best Solution after {generations} gens: x = {population[best_final_idx]:.4f}")
    print(f"Maximum Fitness Achieved: {final_fitness[best_final_idx]:.4f}")

# Execute both
ga_ranking()
ga_roulette()
Why Ranking Avoids Premature Convergence (Exam Favorite)
In Roulette Wheel Selection, probability depends directly on numeric fitness. If early in the run one individual has fitness 100 while others have 5, it gets 95% of the selections. The entire population quickly turns into copies of this single individual, extinguishing all genetic diversity. If that individual was trapped near a local maximum, the GA can never escape.

Ranking Selection solves this: By mapping fitness strictly to ranks (1, 2, 3...), the top individual always has a bounded, constant advantage regardless of how huge its raw numerical score is. Diversity is preserved!
Common Genetic Algorithm Coding Traps
  • Negative Fitness in Roulette: Raw fitness can be negative (e.g. $-(x^2)$). Roulette selection crashes or produces negative probabilities! Always shift fitness: fit - min_fit + eps.
  • Losing the Best Individual: If you mutate every individual without elitism, you can accidentally destroy the best solution found so far! Keep the elite copy untouched.
  • Mutation Range: Using integer addition x + 1 instead of continuous floating perturbation x + random.uniform(-1, 1) turns a continuous problem into discrete stepping.

Practice Questions

Easy: What is the purpose of mutation in a Genetic Algorithm?

Answer: Mutation introduces new genetic material (random diversity) into the population. Without mutation, crossover and selection can only recombine existing genes, inevitably causing the population to stagnate into identical copies (loss of diversity). Mutation allows the algorithm to escape local optima and explore unexplored regions of the search space.

Medium: Compare convergence speed vs stability between Ranking Selection and Roulette Wheel Selection.

Answer:

  • Convergence Speed: Roulette Wheel converges faster when a superior solution is found because it rewards high fitness exponentially/proportionately. Ranking converges at a steadier, moderate pace.
  • Stability: Ranking Selection provides significantly more stable, monotonic improvement across generations because selection pressure is constant and unaffected by extreme fitness outliers. Roulette selection exhibits high variance and instability on small populations.

Hard: Write a Python function for Tournament Selection where k=3 individuals compete. 
def tournament_selection(population, fitness_func, k=3):
    """Pick k random candidates from population; return the one with best fitness."""
    candidates = random.sample(population, k)
    best_candidate = max(candidates, key=fitness_func)
    return best_candidate

Topic 5 Takeaways

  • GA is a population-based global search that uses Darwinian principles: fitness, selection, reproduction, mutation.
  • Ranking Selection: Sorts by fitness; selection depends on rank index. Guarantees constant selection pressure, avoids premature convergence.
  • Roulette Wheel: Selection probability $P(i) \propto f(i)$. Fast but prone to super-individual takeover and requires positive fitness.
  • Controlled Mutation: Applies small random perturbations ($x \leftarrow x + \Delta$) with probability $p_m$ (typically 10%–20%) to maintain diversity.
