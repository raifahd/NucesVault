Strings — Key Methods

Example

String Operations Cheatsheet

s = "  Hello, World!  "
s.strip()            # "Hello, World!"       — remove surrounding spaces

Loops and Range

Example

for loop patterns

for i in range(5):        # 0 1 2 3 4
    print(i)

for i in range(2, 8, 2):  # 2 4 6
    print(i)

# enumerate gives index + value
fruits = ["apple", "banana", "cherry"]
for i, fruit in enumerate(fruits):
    print(f"{i}: {fruit}")
# 0: apple  1: banana  2: cherry

# while with break / continue
attempts = 0
while attempts < 3:
    ans = input("Password: ")
    if ans == "1234":
        print("Correct!"); break
    attempts += 1
else:
    print("Locked.")   # runs only if loop didn't break

Functions

Example

Custom Functions

# Basic
def greet(name):
    print(f"Hello {name}")

# Return value
def add(a, b):
    return a + b

# Multiple return values (returns as a TUPLE)
def stats(nums):
    return min(nums), max(nums), sum(nums) / len(nums)

lo, hi, avg = stats([3, 7, 2, 9])  # unpacking
print(lo, hi, avg)   # 2  9  5.25

# Built-in functions — MUST KNOW
nums = [3, 2, 8, 5, 10]
max(nums), min(nums), sum(nums), len(nums), abs(-7)
sorted(nums)              # [2, 3, 5, 8, 10]  — new list
sorted(nums, reverse=True)# [10, 8, 5, 3, 2]  — new list, descending
Pro Tip
Functions returning multiple values use tuples internally. Unpack them directly: a, b = my_func(). The for...else pattern (else runs only if loop never broke) is a Python trick examiners love.
Common Mistake
range(1, 5) gives 1, 2, 3, 4 — NOT 5. The stop value is always exclusive. Also range() returns integers only — cannot use floats as step.

Key Takeaways

  • Use f"text {var}" for string formatting — cleanest syntax
  • range(start, stop, step) — stop is always exclusive
  • Functions can return multiple values: unpacked as a, b = func()
  • Know by heart: max(), min(), sum(), len(), abs(), sorted()
  • for...else: else block runs only if loop ended without break
Practice Questions
Easy: What does "hello world".split() return?

Answer: ['hello', 'world'] — split() with no argument splits on whitespace and strips empty strings.

Medium: Write a function that returns (count_positive, count_negative, count_zero) from a list. 
def classify(nums):
    pos = len([n for n in nums if n > 0])
    neg = len([n for n in nums if n < 0])
    zero = len([n for n in nums if n == 0])
    return pos, neg, zero

p, n, z = classify([3, -1, 0, 5, -2, 0])
print(p, n, z)  # 2 2 2
Hard: Word frequency counter that ignores lines starting with '#', case-insensitive. 
counts = {}
while True:
    line = input("Enter line (or 'done'): ")
    if line == 'done': break
    if line.startswith('#'): continue
    for word in line.strip().lower().split():
        counts[word] = counts.get(word, 0) + 1
for word, freq in counts.items():
    print(f"{word}: {freq}")

2Lists and List Comprehensions

The most-used data structure — mutable, ordered, indexed

A list is like a row of numbered boxes. You can put anything in any box, rearrange them, add or remove boxes. Lists are mutable (changeable) and ordered (indexed from 0).

Index 0 1 2 3 4
Value 9 41 12 3 74
Neg Index -5 -4 -3 -2 -1
Example

All list operations you need

t = [9, 41, 12, 3, 74, 15]

# Slicing  [start:stop]  — stop is EXCLUSIVE
t[1:3]   # [41, 12]
t[:4]    # [9, 41, 12, 3]
t[3:]    # [3, 74, 15]
t[-3:]   # [3, 74, 15]   ← last 3
t[:]     # full copy

# Mutation (unlike strings/tuples)
t[3] = 10
t[:3] = [1, 2, 3]

# Methods — memorize these
t.append(99)         # add to end
t.insert(2, 50)      # insert 50 at index 2
t.remove(41)         # remove first occurrence
t.pop()              # remove + return last
t.pop(1)             # remove + return at index 1
t.sort()             # sort in-place ascending
t.sort(reverse=True) # sort in-place descending
t.reverse()          # reverse in-place
t.count(3)           # count occurrences
t.index(74)          # index of first occurrence
t.extend([100,200])  # add multiple items

# Concatenation
[1,2,3] + [4,5,6]   # [1,2,3,4,5,6]

# Membership
9 in t        # True
20 not in t   # True

List Comprehensions

Definition
List Comprehension: A concise one-liner to build a list by applying an expression to each item in an iterable, optionally filtered by a condition.

Syntax: [expression for item in iterable if condition]
Example

Comprehension Patterns

# Pattern 1: Basic transform
squares = [n**2 for n in range(10)]
# [0, 1, 4, 9, 16, 25, 36, 49, 64, 81]

# Pattern 2: Filter + transform
planets = ['Mercury', 'Venus', 'Earth', 'Mars', 'Jupiter']
short = [p.upper() + '!' for p in planets if len(p) < 6]
# ['VENUS!', 'EARTH!', 'MARS!']

# Pattern 3: Count trick — True=1, False=0
nums = [-5, -1, 0, 3, 7, -2]
count_neg = sum(n < 0 for n in nums)  # 3  ← elegant!

# Pattern 4: Filter to create cleaned list
readings = [23, 45, -999, 30, -999, 50]
cleaned = [r for r in readings if r != -999]
# [23, 45, 30, 50]

# Pattern 5: Squares of positives only
squares_of_pos = [n**2 for n in nums if n > 0]
# [9, 49]
Exam Hint
Labs often ask you to rewrite a for-loop as a list comprehension. Template: [expression for item in iterable if condition]. The if is optional — only add when filtering.
Common Mistake
t.sort() sorts in-place and returns None. Never write t = t.sort() — this makes t disappear! Use sorted(t) if you need a new list.

Key Takeaways

  • Lists are mutable and ordered — indexed from 0, negative from -1
  • Slicing: t[start:stop] — stop is exclusive
  • Key methods: append, insert, remove, pop, sort, reverse, extend, count, index
  • Comprehension: [expr for item in iterable if cond]
  • sorted(lst) returns new list; lst.sort() modifies in place (returns None)
Practice Questions
Easy: Given t = [9, 41, 12, 3, 74], what does t[-3:] return?

Answer: [12, 3, 74] — the last 3 elements.

Medium: Get squares of all positive numbers from [-3, 2, -1, 5, 0, 4] using list comprehension.

Answer: [n**2 for n in [-3,2,-1,5,0,4] if n > 0] → [4, 25, 16]

Hard: Get top-2 most sold items from a sales dict without hardcoding. 
sales = {"apple":120,"banana":85,"milk":200,"bread":150,"eggs":90}
# sorted() with key=lambda sorts by second element of each tuple
sorted_sales = sorted(sales.items(), key=lambda x: x[1], reverse=True)
top2 = sorted_sales[:2]
print(top2)  # [('milk', 200), ('bread', 150)]

3Dictionaries

Key-value pairs — the most important structure for counting, mapping, and storing data

Dictionaries are like a phone book: look up by name (key) to get the number (value). Keys must be unique and immutable. Values can be anything.

Definition
Dictionary: An unordered (ordered since Python 3.7), mutable collection of key-value pairs. O(1) lookup by key. Keys must be unique and hashable (strings, numbers, tuples).
Example

Complete Dictionary Operations

# Creating
d = {}
d = {'name': 'Ali', 'age': 20}
d = dict(name='Ali', age=20)

# Reading — ALWAYS use .get() to be safe!
d['name']           # 'Ali'
d.get('age')        # 20
d.get('gpa', 0)     # 0  (default if key missing — NO crash)
# d['gpa']  ← KeyError crash if key doesn't exist!

# Writing
d['email'] = 'ali@mail.com'   # add
d['age'] = 21                  # update

# Checking
'name' in d    # True
'gpa' in d     # False

# Removing
del d['email']            # raises KeyError if missing
d.pop('age')              # removes + returns value
d.pop('gpa', None)        # safe — no error if missing

# Iterating
for key in d:             # keys only
    print(key, d[key])

for k, v in d.items():   # key-value pairs ← PREFER THIS
    print(k, v)

# Views
list(d.keys())   # ['name', 'age']
list(d.values()) # ['Ali', 20]
list(d.items())  # [('name','Ali'), ('age',20)]

The Counting Pattern — Most Common Lab Pattern

Example

Word / Item Frequency Counter

words = ['Ali', 'Ahmed', 'Ali', 'Zain', 'Ahmed', 'Ali']

# THE pattern — use this always:
counts = {}
for word in words:
    counts[word] = counts.get(word, 0) + 1
# {'Ali': 3, 'Ahmed': 2, 'Zain': 1}

# Sort by value (frequency) — descending
sorted_counts = sorted(counts.items(), key=lambda x: x[1], reverse=True)
# [('Ali',3), ('Ahmed',2), ('Zain',1)]

# Top 2
for word, freq in sorted_counts[:2]:
    print(f"{word}: {freq}")
Pro Tip
dict.get(key, default) never crashes. Always use it when counting: counts[x] = counts.get(x, 0) + 1. This one pattern solves half the dict problems in labs.
Common Mistake
Accessing a missing key directly (d['missing']) raises a KeyError. Always use d.get(key) or check if key in d first.

Key Takeaways

  • Dictionaries are key-value stores — O(1) lookup by key
  • Use .get(key, default) to safely read without crashing
  • Counting pattern: counts[x] = counts.get(x, 0) + 1
  • Iterate pairs with for k, v in d.items()
  • Sort by value: sorted(d.items(), key=lambda x: x[1], reverse=True)
Practice Questions

Tuples

Definition
Tuple: An ordered, immutable sequence. Like a list you cannot change after creation. Used for: multiple return values, dictionary keys, coordinate pairs.
Example

Tuple Operations

# Creating
t = (12, 5, 75)
t = 12, 5, 75        # parentheses are optional!
single = ("apple",)  # ONE-item tuple needs trailing comma
NOT_tuple = ("apple") # This is just a string!

# Accessing
t[0]   # 12
t[-1]  # 75
len(t) # 3

# Unpacking — VERY COMMON
a, b, c = (1, 2, 3)
(x, y) = (4, 'fred')

# Functions returning tuples (very common pattern)
def min_max(lst):
    return min(lst), max(lst)   # returns a tuple

lo, hi = min_max([3,7,1,9,2])  # unpack immediately

# dict.items() returns tuples — that's why this works:
d = {'a':10, 'b':20}
for k, v in d.items():   # unpacking each (key,value) tuple
    print(k, v)

# Only 2 tuple methods
t = (1, 3, 7, 8, 7, 5)
t.count(7)  # 2  — occurrences
t.index(8)  # 3  — first index

# IMMUTABLE — these ALL fail:
# t[0] = 99    TypeError
# t.sort()     AttributeError
# t.append(5)  AttributeError

Sets

Definition
Set: An unordered collection of unique items. Automatically removes duplicates. Fast O(1) membership testing — like a dictionary with only keys.
Example

Set Operations

# Creating
s = {1, 2, 3}
s = set()             # empty set — NOT {}!  {} is empty dict
s = set([1,2,2,3])    # from list: removes dupes → {1,2,3}

# Duplicates auto-removed
s = {"apple","banana","cherry","apple"}  # {"apple","banana","cherry"}

# Adding
s.add("orange")
s.update(["kiwi","lime"])  # add multiple from list/set

# Removing
s.remove("banana")   # raises KeyError if not found
s.discard("banana")  # NO error if not found ← SAFER

s.pop()    # remove a RANDOM item (unordered!)
s.clear()  # empty set

# Membership (fast O(1))
"apple" in s   # True

# Set math
a = {1,2,3,4}; b = {3,4,5,6}
a | b   # union:        {1,2,3,4,5,6}
a & b   # intersection: {3,4}
a - b   # difference:   {1,2}

# PRACTICAL: remove duplicates from a list
names = ["Ali","Ahmed","Ali","Zain"]
unique = list(set(names))  # ["Ali","Ahmed","Zain"]
Exam Hint
Sets are perfect for uniqueness problems and for tracking visited nodes in search algorithms. Every BFS/DFS implementation uses visited = set() to avoid infinite loops.
Common Mistake
{} creates an empty dict, not an empty set! Use set() for an empty set. Also, True and 1 are considered identical in sets: {True, 1, 2} → {True, 2}.

Key Takeaways

  • Tuples are immutable — use for fixed data, multiple return values, dict keys
  • Single-item tuple: (x,) with trailing comma — not (x)
  • Sets automatically deduplicate and have O(1) membership testing
  • Use discard() over remove() for safe deletion without crashes
  • Empty set = set(), NOT {}
Practice Questions

Answer: It creates a string, not a tuple. Python treats parentheses around a single value as grouping. Use ("apple",) with a trailing comma.

Complete solutions to all lab task types — study these carefully

Problem 1: Student Performance Analyzer

Full Solution
n = int(input("Number of students: "))
students = {}

for _ in range(n):
    name = input("Name: ")
    marks = [int(input(f"  Subject {i+1} marks: ")) for i in range(3)]
    students[name] = marks

top_student, top_avg = None, -1
class_total = 0

for name, marks in students.items():
    total = sum(marks)
    avg = total / len(marks)
    class_total += avg

    if avg >= 85:   grade = 'A'
    elif avg >= 70: grade = 'B'
    elif avg >= 50: grade = 'C'
    else:           grade = 'F'

    print(f"{name}: Total={total}, Avg={avg:.2f}, Grade={grade}")

    if avg > top_avg:
        top_avg = avg; top_student = name

print(f"\nClass Avg: {class_total/len(students):.2f}")
print(f"Top Student: {top_student}")

Problem 2: Login Validation with 3 Attempts

Full Solution
users = {"admin":"1234","ali":"pass123","ahmad":"abcd"}

for attempt in range(3):
    username = input("Username: ")
    password = input("Password: ")

    if username not in users:
        print("Invalid username"); continue
    if users[username] != password:
        print("Wrong password"); continue

    print("Login successful!"); break
else:
    # Runs ONLY if loop ended without break
    print("Account locked after 3 failed attempts.")

Pro Tip
The for...else in the login example is a Python trick: the else block runs only if the loop completed without hitting break. This is perfect for "if no success after N tries" logic.

Labs 1 and 2 Complete Summary

  • Lists: mutable, ordered — comprehension: [expr for x in lst if cond]
  • Dicts: key → value — always use .get(k, default) for safe reads
  • Tuples: immutable — perfect for multiple return values and unpacking
  • Sets: unique items — deduplicate lists, track visited nodes in search
  • Counting pattern: counts[x] = counts.get(x, 0) + 1
  • Sort by value: sorted(d.items(), key=lambda x: x[1], reverse=True)
