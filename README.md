## Overview

**NucesVault** delivers standalone, zero-dependency interactive notes designed for deep concept clarity, rapid exam revision, and active recall. Each module runs entirely in any modern browser without servers or build steps.

```
NucesVault/
└── S5/
    ├── Artifical Intelligence (AI)/
    │   └── index.html
    └── Data Warehousing & Business Intelligence/
        └── index.html
```

## Download & Offline Usage

### Option 1: Clone the Entire Repository (Recommended)

```bash
git clone https://github.com/raifahd/NucesVault.git
cd NucesVault
```
> Double-click any `index.html` file inside the course directories to open it instantly in your default web browser.

### Option 2: Download Specific Course HTML

#### Artificial Intelligence (AI)
```bash
curl -O https://raw.githubusercontent.com/raifahd/NucesVault/main/S5/Artifical%20Intelligence%20(AI)/index.html
```

#### Data Warehousing & Business Intelligence (DW & BI)
```bash
curl -O https://raw.githubusercontent.com/raifahd/NucesVault/main/S5/Data%20Warehousing%20%26%20Business%20Intelligence/index.html
```

### Option 3: Manual Direct Download via Browser

1. Navigate to the desired course folder above on GitHub.
2. Click on `index.html`.
3. Click the **Download raw file** button in the top right.
4. Save and open the file directly in Chrome, Firefox, Safari, or Edge.
